Стоимость поиска по окну: почему храним коды, а не id токенов

Окно W = 262 144, d = 192, L = 8, S = 12 подвекторов. Все FLOPs — аналитическая оценка из размеров модели (chaotic-llm/phase01/exp_vq/models_pc.py), не замер на GPU. Нижняя ось — память на токен (Б); правая ось — вычисления на один запрос к окну.

Token IDs (~9 бит) — абсолютный пол памяти, но для селекции бесполезны. База (h FP32) и keys-T5 тратят 768–792 Б/ток. Fracode-коды: 24–96 Б/ток.

Чтобы выбрать драйвер из id токенов, надо прогнать весь контекст W через модель (~155 GFLOP). Чтобы выбрать из Fracode-кодов — только ADC-сумма по кодам (~50 MFLOP), без прогона. Разница ~3000×. Точный косинус по (W,d) — промежуточный вариант, тоже дорог по bandwidth.
